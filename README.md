# Kutflow

Kutflow is an experiment in turning intent into action.

It starts with a **wish**: something you want to happen.

A wish is understood, questioned, refined, and broken into meaningful **commits**. Related commits
form **branches** that can be pursued independently.

At every step, decisions can be made by a human, a machine, or both.

The goal is simple: describe **what you want**, then let the path toward it emerge.
